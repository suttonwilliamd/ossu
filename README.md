# OSSU
## The Open Source Screenshot Utility

Inspired by UOSU, the Ultima Online Screenshot Utility.

An independent Windows screenshot utility preserving the classic workflow: folder, hotkey, repeated captures and named files. No uploads, accounts, telemetry or game injection. Not an official UOSU update.

## Status

William selected Go for the implementation. The previous C#/.NET Framework implementation and generated build output have been removed from the working project. No Go implementation has been started.

Project repository: https://github.com/suttonwilliamd/ossu. Coordinator setup is authorized; implementation is not yet authorized.
